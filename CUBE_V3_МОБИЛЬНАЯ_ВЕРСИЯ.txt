CUBE V3 MOBILE FIRST

Что изменено:
- мобильная версия спроектирована отдельно;
- компактная шапка;
- анимированный бургер;
- большой текст без переполнения;
- фирменный баннер скрыт на телефоне, логотип остаётся;
- карточки оптимизированы под палец;
- соцсети выглядят как мобильные кнопки;
- добавлена фиксированная нижняя панель «Позвонить / Записаться»;
- уменьшены пустые промежутки;
- улучшены очень маленькие экраны.

Как обновить:
1. Распаковать архив.
2. GitHub → Add file → Upload files.
3. Загрузить все файлы.
4. Commit changes.
5. Подождать 1 минуту.
6. На телефоне открыть сайт заново или очистить кэш браузера.
