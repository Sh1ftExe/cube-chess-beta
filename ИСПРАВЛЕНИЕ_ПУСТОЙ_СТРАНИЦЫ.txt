CUBE V2 STABLE — ИСПРАВЛЕНИЕ ПУСТОЙ СТРАНИЦЫ

Причина:
JavaScript не загрузился или завершился с ошибкой, а контент был скрыт анимацией.

В этой версии:
- весь основной контент находится прямо в index.html;
- контент всегда виден;
- JavaScript только улучшает сайт;
- если JavaScript не загрузится, сайт всё равно останется рабочим;
- картинки лежат в корне репозитория.

КАК ОБНОВИТЬ:
1. Распакуйте архив.
2. GitHub → Add file → Upload files.
3. Загрузите ВСЕ файлы из папки.
4. Нажмите Commit changes.
5. Подождите 1 минуту.
6. Откройте сайт и нажмите Ctrl + Shift + R.
