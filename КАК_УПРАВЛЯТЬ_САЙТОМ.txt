БЕСПЛАТНАЯ БЕТА-ВЕРСИЯ CUBE

ЧТО ИЗМЕНЕНО
- Вся изменяемая информация вынесена в site-data.js.
- Добавлен admin.html — простая локальная панель.
- Сайт готов для бесплатной публикации через GitHub Pages.

КАК МЕНЯТЬ ДАННЫЕ НА КОМПЬЮТЕРЕ
1. Откройте admin.html.
2. Измените турнир, дату, время, цену, телефон или адрес.
3. Нажмите «Скачать site-data.js».
4. Замените старый site-data.js скачанным файлом.
5. Откройте index.html и проверьте изменения.

КАК МЕНЯТЬ ДАННЫЕ ПОСЛЕ ПУБЛИКАЦИИ НА GITHUB
1. Откройте репозиторий сайта.
2. Нажмите на site-data.js.
3. Нажмите значок карандаша Edit.
4. Измените нужное значение в кавычках.
5. Нажмите Commit changes.
6. Через несколько минут GitHub Pages обновит сайт.

ВАЖНО
- Не удаляйте кавычки и запятые в site-data.js.
- Телефон phoneInternational пишется только цифрами: 79279571999.
- admin.html является удобным генератором файла, но не защищённой онлайн-админкой.
- Для настоящей онлайн-админки с логином позже понадобится CMS или база данных.
