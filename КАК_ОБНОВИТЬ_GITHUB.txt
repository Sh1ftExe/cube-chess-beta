КАК ОБНОВИТЬ САЙТ
1. Распакуйте архив.
2. В GitHub откройте репозиторий cube-chess-beta.
3. Нажмите Add file → Upload files.
4. Перетащите все файлы из этой папки.
5. Разрешите GitHub заменить существующие файлы.
6. Нажмите Commit changes.
7. Подождите 30–60 секунд.
8. Обновите сайт сочетанием Ctrl + F5.
