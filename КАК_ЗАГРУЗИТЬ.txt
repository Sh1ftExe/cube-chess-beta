КАК ЗАГРУЗИТЬ:
1. Распакуйте архив.
2. В GitHub откройте cube-chess-beta.
3. Add file → Upload files.
4. Перетащите ВСЕ файлы из папки CUBE_V2_GITHUB_FLAT.
5. Нажмите Commit changes.
6. Подождите 1 минуту.
7. Откройте сайт и нажмите Ctrl + F5.
